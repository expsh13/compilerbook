# 自分で育てる教科書

「低レイヤを知りたい人のためのCコンパイラ作成入門」を読みながら作った、図解と操作で学ぶ全９章の学習用教科書です。

- [教科書を読む](https://expsh13.github.io/compilerbook/)
- [原書を読む](https://www.sigbus.info/compilerbook)

原書そのものではなく、理解を助ける説明・SVG図解・操作できる教材をまとめています。各章末に原書と参照先を掲載しています。

## 章の構成

1. 機械語とアセンブラ
2. 電卓レベルの言語の作成
3. 分割コンパイルとリンク
4. 関数とローカル変数
5. コンピュータにおける整数の表現
6. ポインタと文字列リテラル
7. プログラムの実行イメージと初期化式
8. スタティックリンクとダイナミックリンク
9. Cの型の構文

## 手元で読む

リポジトリのルートで、次を実行します。

```sh
python3 -m http.server 8765 --directory textbook
```

ブラウザで `http://localhost:8765/` を開きます。

## 更新と公開

教材は `main` ブランチの `textbook/` にあります。変更をコミットして `main` にプッシュすると、GitHub Actionsがテストを実行し、成功した教材をGitHub Pagesへ自動公開します。テスト用ファイルは公開サイトには含めません。

公開の進捗はリポジトリの「Actions」で確認できます。「教科書を自動公開」は手動でも実行できます。旧方式の `gh-pages` ブランチと公開スクリプトは使用しません。

テストのみ実行する場合は、Node.jsを用意して次を実行します。

```sh
node --test textbook/tests/*.test.*
```
